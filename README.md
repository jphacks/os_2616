## 製品概要

### 背景(製品開発のきっかけ、課題等）
一人暮らしの高齢者や、離れて暮らしている家族がいる人にとって、毎日の安否確認は大切です。しかし、何度も電話やメッセージで確認すると、お互いに負担になることがあります。
また、センサーの反応がしばらくない場合でも、ただ外出しているだけなのか、体調が悪いのかを判断するのは難しいです。
そこで、本人のプライバシーを守りながら、離れて暮らす家族が安心できる見守りシステム「ミマモリンク」を開発しました。
### 製品説明（具体的な製品の説明）
ミマモリンクは、センサーとWebアプリを連携させて、離れて暮らす家族の生活の様子を確認できる見守りシステムです。
センサーで人の動きを確認し、一定時間反応がない場合は、本人側の画面に状態を確認するメッセージを表示します。
また、本人が自分の状態を伝えたり、必要なときに家族へ連絡したりできる仕組みも取り入れています。家族が一方的に見守るのではなく、お互いに安心できることを目指しています。
### 特長
#### 1. 特長1
**プライバシーに配慮した非侵襲見守り**
カメラやマイクを一切使用せず、PIRmotionセンサー等による生活動線（起床、キッチン、トイレ、リビングなど）の検知のみで日常の安心を把握します
#### 2. 特長2
**リアルタイムな双方向リンクと状態管理**
#### 3. 特長3
**無反応時の自動確認と緊急連絡**
一定時間センサーに反応がない場合、本人側の画面に確認ダイアログを表示します。本人が「元気です」「体調が悪い」などの状態を選択でき、必要に応じて電話による連絡につなげます。

### 解決出来ること
-離れて暮らす家族が過度なプレッシャーを与えることなく、日常の安否や生活リズムを自然に把握できる。
-センサーの一定時間無反応時に、システムが自動でご本人へ優しく状態確認（声かけ）を行い、見守り漏れや連絡遅延を防ぐ。
-緊急時や不調時にワンタップで電話発信や状態報告が行え、迅速なコミュニケーションを促す。
### 今後の展望
-実機（IoTハードウェア）との通信安定性向上および数の増設。
-通知履歴の蓄積・グラフ化による、生活リズムの長期的な変化や健康予兆検知機能の拡張。
-複数家族での見守りシェアや、より多様なセンサーデバイスへの対応。
### 注力したこと（こだわり等）
* カメラやマイクを使用せず、センサーによる生活動線の検知を活用することで、本人のプライバシーと尊厳に配慮した見守りを目指しました。
* 単にセンサーの反応がないことを通知するのではなく、まず本人に定期的に状態を確認する仕組みを取り入れ、不要な心配や過度な干渉を減らすことにこだわりました。
