### 背景(製品開発のきっかけ、課題等）
一緒に住めない・遠くで暮らしているご高齢の家族に過度な干渉（カメラ設置のプライバシーの侵害など）を避けた自然な見守りシステムがあればいいなと考えました。しかし従来のセンサー通知システムでは「単に反応がない場合」にどこまで気に掛けたらいいのか判断しにくく、リアルタイムかつ心理的負担のない双方向のコミュニケーション能力が必要なことが課題だと考えました。

### 製品説明（具体的な製品の説明）
ミマモリンクは、**M5GO（M5Stack IoT Starter Kit V2.7）の人感センサー**と、**PCサーバー・家族用Web画面・LINE**を連携させた見守りシステムです。(デモ段階のため、サーバーなどは指定されたインターネットに接続することが必要)

1. 自宅に置いたM5GOが人の動きを検知し、PCのサーバーへ送信します。動きがないときも定期的に通信し、機器が正常に動いていることを知らせます。
2. 一定時間動きがない、または機器との通信が途絶えたときは、ご家族の**LINEに自動で通知**します。
3. ご家族はLINEの下画面にあるバナーを押すと、現在の状態・最後に動きを検知した時刻・通知の記録をいつでも確認できます。必要
に応じて、簡単に電話もかけられます。
   
### 特長
#### 1. 特長1
**プライバシーに配慮した非侵襲見守り**
カメラやマイクは一切使用せず、PIR（人感）センサーで動きの有無だけを検知します。見守られる側は特別な操作をする必要なし、カメラで撮影される必要もなしで、普段通りに過ごすだけで家族に安心を届けられます。
https://github.com/user-attachments/assets/ac8d1a08-2dff-42e1-8248-27a11f5485ed

#### 2. 特長2
**リアルタイムな双方向リンクと状態管理**
M5GOは、動きがあれば2秒ごと、動きがなくても10秒ごとにサーバーへ通信します。サーバーはこれをもとに、毎秒、次の4つの状態を判定します。

接続待ち：まだM5GOから通信がない
見守り中：一定時間内に動きがある
要連絡：一定時間以上、動きがない
通信なし：M5GOからの通信が途絶えている

家族用Web画面は2秒ごとに最新の状態を取得し、色と文章で分かりやすく表示します。「本人に動きがない」のか「機器が止まっている」のかを区別できるのも大きな特長です。
あらかじめ電話番号を設定すれば、スムーズに電話をかけられます。
https://github.com/user-attachments/assets/0069ba79-dc73-40ee-b515-0958ae9219af

#### 3. 特長3
**LINEへの自動通知で、見ていなくても気づける**

異常を検知すると、ご家族のLINEに自動でメッセージを送ります。詳しく知りたい場合は画面下のバナーをタップすることで、「お母さま（リビング）」のように、Web画面で登録した呼び名とセンサーの場所が入ります。設定すれば、ご家族から電話をかけることもできます。

同じ異常は1回だけ通知し、何度も鳴らしません。
動きや通信が戻ったときも、「動きを検知しました」「通信が復旧しました」と知らせます。
LINEへの送信に失敗したら、10秒ごとに自動で再送します。
通知の内容と送信結果はファイルに保存され、Web画面の「通知の記録」で確認できます。
https://github.com/user-attachments/assets/c8bd2a4b-a40e-48e2-a90e-42c49e1946c3

### 解決出来ること
離れて暮らす家族が、相手に負担やプレッシャーを与えることなく、日々の安否や生活リズムを自然に把握できる。
センサーが一定時間反応しないときに、LINEで自動通知されるので、家族が画面を見ていなくても異常に気づける。見守り漏れや連絡の遅れを防げる。
異常の原因が「本人」なのか「機器（電源やWi-Fi）」なのかを区別でき、不要な心配や見落としを減らせる。
気になったときは、設定していればWeb画面から電話をかけ、すぐに本人へ連絡できる。

### 今後の展望
サーバーで公開し、どこでも見守りを出来るようにする。
実機（IoTハードウェア）との通信の安定性を高め、センサーを複数台に増やして部屋ごとの生活動線を把握できるようにする。
通知履歴を蓄積・グラフ化し、生活リズムの長期的な変化や、体調の予兆に気づける機能へ拡張する。
複数の家族で見守り情報を共有できるようにし、より多様なセンサーデバイスにも対応する

### 注力したこと（こだわり等）
* **LINE通知を確実に、うるさくなく届ける仕組み**
  * 同じ異常は1回だけ通知し、回復したときにも知らせることで、家族が状況の変化を追えるようにしました。
  * 送信は待ち行列で管理し、失敗しても自動で再送します。送信結果（送信待ち・送信済み・失敗）も記録しています。
* **止まらない・壊れない作り**
  * M5GOはWi-Fiが切れても自動で再接続し、サーバーが応答しなくても5秒で処理を打ち切ります。
  * サーバーは、通知の記録と設定を一時ファイル経由で保存し、途中で止まってもデータが壊れないようにしました。
* **家族が迷わない画面**
  * 状態を画面の一番上に大きく表示し、普段は見る必要のない設定は折りたたみました。
  * 電話番号のハイフンは自動で取り除き、入力ミスには日本語のメッセージを表示します。
* **自動テストで動作を保証**
  * unittestで17項目のテストを用意しました。通知が1回だけ届くこと、再送、記録の保存と件数の上限、設定の検証などを確認しています。
 
## 開発技術

* HTTP API：M5GOからPCサーバーへのセンサーデータ送信、家族用画面への状態データ提供

* LINE Messaging API：ご家族のLINEへの通知（pushメッセージ）

#### フレームワーク・ライブラリ・モジュール
* Arduino IDE（C++）：M5GO側のプログラム開発
* M5Unified：M5GO本体の画面・機能の制御
* WiFi.h、HTTPClient.h：Wi-Fi接続およびHTTP通信
* Python、Flask：PC側サーバーの構築
* HTML、CSS、JavaScript：家族用見守り画面の開発
* requests：LINE Messaging APIへのリクエスト送信
* unittest：自動テスト
* claude：技術サポート
#### デバイス
* M5GO IoTスターターキット　V2.7（M5GO本体、PIRユニット）
* スマートフォン（家族用見守り画面、LINEの受信）

### 独自技術
#### ハッカソンで開発した独自機能・技術
**ハートビート方式による状態管理と、一度きり通知・自動再送の仕組み**

* **ハートビート方式の状態判定**（server.py の current_status()）
  M5GOは、動きがないときも定期的に「動きなし」を送信します（ハートビート）。サーバーは「最後に動きがあった時刻」と「最後に通信があった時刻」を別々に記録し、毎秒「接続待ち／見守り中／要連絡／通信なし」を判定します。これにより、**本人の異常と機器の異常を区別**できます。
* **一度きり通知と自動再送**（server.py の check_once()）
  異常の種類ごとに通知済みかどうかを記録し、同じ通知を繰り返し送らないようにしました。送信は待ち行列で管理し、LINEへの送信に失敗したら一定時間後に自動で再送します。
