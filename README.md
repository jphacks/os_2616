## 製品概要

### 背景(製品開発のきっかけ、課題等）
一緒に住めない・遠くで暮らしているご高齢の家族に過度な干渉（カメラ設置のプライバシーの侵害など）を避けた自然な見守りシステムがあればいいだろうなと考えました。しかし従来のセンサー通知システムでは「単に反応がない場合」にどこまで気に掛けたらいいのか判断しにくく、リアルタイムかつ心理的負担のない双方向のコミュニケーション能力が必要なことが課題だと考えました。

### 製品説明（具体的な製品の説明）
ミマモリンクは、**M5GO（M5Stack IoT Starter Kit V2.7）の人感センサー**と、**PCサーバー・家族用Web画面・LINE**を連携させた見守りシステムです。(デモ段階のため、サーバーなどは指定されたインターネットに接続することが必要)

1. 自宅に置いたM5GOが人の動きを検知し、PCのサーバーへ送信します。動きがないときも定期的に通信し、機器が正常に動いていることを知らせます。
2. 一定時間動きがない、または機器との通信が途絶えたときは、ご家族の**LINEに自動で通知**します。
3. ご家族はLINEの下画面にあるバナーを押すと、現在の状態・最後に動きを検知した時刻・通知の記録をいつでも確認できます。必要に応じて、簡単に電話もかけられます。
   
### 特長
#### 1. 特長1
**プライバシーに配慮した非侵襲見守り**
カメラやマイクは一切使用せず、PIR（人感）センサーで動きの有無だけを検知します。見守られる側は特別な操作をする必要なし、カメラで撮影される必要もなしで、普段通りに過ごすだけで家族に安心を届けられます。

#### 2. 特長2
**リアルタイムな双方向リンクと状態管理**
M5GOは、動きがあれば2秒ごと、動きがなくても10秒ごとにサーバーへ通信します。サーバーはこれをもとに、毎秒、次の4つの状態を判定します。

接続待ち：まだM5GOから通信がない
見守り中：一定時間内に動きがある
要連絡：一定時間以上、動きがない
通信なし：M5GOからの通信が途絶えている

家族用Web画面は2秒ごとに最新の状態を取得し、色と文章で分かりやすく表示します。「本人に動きがない」のか「機器が止まっている」のかを区別できるのも大きな特長です。

#### 3. 特長3

### 解決出来ること
-離れて暮らす家族が過度なプレッシャーを与えることなく、日常の安否や生活リズムを自然に把握できる。
-センサーの一定時間無反応時に、システムが自動でご本人へ優しく状態確認（声かけ）を行い、見守り漏れや連絡遅延を防ぐ。
-緊急時や不調時にワンタップで電話発信や状態報告が行え、迅速なコミュニケーションを促す。
### 今後の展望
-実機（IoTハードウェア）との通信安定性向上および数の増設。
-通知履歴の蓄積・グラフ化による、生活リズムの長期的な変化や健康予兆検知機能の拡張。
-複数家族での見守りシェアや、より多様なセンサーデバイスへの対応。

## 開発技術
### 活用した技術
#### API・データ
* HTTP API：M5GOからPCサーバーへのセンサーデータ送信、家族用画面への状態データ提供
* JSON：センサーデータおよび通知履歴の管理

#### フレームワーク・ライブラリ・モジュール
* Arduino IDE（C++）：M5GO側のプログラム開発
* M5Unified：M5GO本体の画面・機能の制御
* WiFi.h、HTTPClient.h：Wi-Fi接続およびHTTP通信
* Python、Flask：PC側サーバーの構築
* HTML、CSS、JavaScript：家族用見守り画面の開発
* requests：LINE Messaging APIへのリクエスト送信
* unittest：自動テスト
#### デバイス
* M5GO IoTスターターキット　V2.7


### 独自技術
#### ハッカソンで開発した独自機能・技術
一定時間の無動作を検知してご本人側画面へインタラクティブな確認ダイアログ（声かけ・状態応答）をトリガーするタイムアウト・ステータス管理ロジック
