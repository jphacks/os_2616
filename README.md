# ミマモリンク

M5GO IoT Kit v2.7 と Unit PIR（人感センサー：人の体温の動きを感じ取る部品）で動きを検知し、PCのサーバーで見守るしくみです。

- 家族用画面 `http://<PCのIPアドレス>:5000/` に、最後に動きを検知した日時を自動表示します（2秒ごとに更新）
- 30秒間動きがなければ LINE に通知します（1回だけ。動きが戻ると「動きを検知しました」と通知）
- M5GO からの通信が60秒途絶えたら LINE に通知します（復旧したときも通知）
- 通知を出すたびに「通知の記録」を残し、家族用画面に新しい順で表示します（下の「通知の記録」参照）
- 家族用画面で「見守る方」「連絡先の電話番号」「センサーの場所」を設定できます（下の「見守りの設定」参照）

## しくみ（動きの検知から LINE 通知まで）

1. Unit PIR が動きを感じると、信号線が HIGH（電気が流れている状態）になります。約2秒続き、動き続けると延長されます。
2. M5GO が GPIO36 を 0.1秒ごとに読み、HIGH なら PC に `{"motion":true}` を送ります（動き続けている間は2秒おき）。
3. 動きがなくても、M5GO は10秒ごとに `{"motion":false}` を送ります。これは「M5GO は動いています」という合図です。
4. server.py は最後に動きを受け取った時刻を記録し、家族用画面は2秒ごとにそれを表示します。
5. server.py は1秒ごとに確認し、30秒間 `true` が来なければ LINE を1通送ります。送信に失敗したら10秒後に送り直します。
6. M5GO から何も届かない状態が60秒続いたら「通信が途絶えています」と LINE を送ります。

## 通知の記録

LINE 通知を出すたびに、次の内容を記録します。

| 項目 | 内容 |
| --- | --- |
| 日時 | 通知のきっかけが起きた時刻（例：30秒動きがないと判断した時刻） |
| 種類 | 動きがありませんでした / 機器との通信が途絶えました / 動きを再び検知しました / 機器との通信が復旧しました |
| 最後の動き | その時点で最後に動きを検知した時刻 |
| LINE | 送信済み（送信した時刻）/ 送信に失敗（10秒ごとに再送中）/ 送信待ち |

- 記録は `data/notifications.json` に保存されます。サーバーを起動し直しても消えません（新しいもの100件まで）。
- 家族用画面には新しい順に20件まで表示し、2秒ごとに自動で更新します。
- 記録を消したいときは、サーバーを止めてから `data/notifications.json` を削除します。
- LINE のトークンやユーザーIDは、このファイルには保存されません。

## 見守りの設定

家族用画面の右側「見守りの設定」の「変更する」を押すと、次の3つを設定できます。入力欄から離れる（または Enter を押す）と自動で保存されます。

| 設定 | 使われる場所 |
| --- | --- |
| 見守る方（お母さま / お父さま / 自分で入力したお名前） | 画面の文（例：「お母さまの動きはいつもの範囲です」）と LINE の文 |
| 連絡先の電話番号 | 「要連絡」のときに「〇〇 に電話する」ボタンを表示（スマホで押すと電話がかかります）。ハイフンや空白は自動で取り除きます |
| センサーの場所 | 画面の「センサー」欄と LINE の文（例：「ミマモリンク：お母さま（リビング）の様子：30秒間、動きが検知されていません。」） |

- 設定は `data/settings.json` に保存され、サーバーを起動し直しても残ります。
- 同じ家族用画面を開いている全員に、同じ設定が表示されます。
- 注意: 家族用画面を開ける人（同じネットワークにいる人）なら誰でも設定を変更できます。
- LINE の文は、通知を出した時点の設定で作られます。あとから設定を変えても、すでに記録された通知の文は変わりません。

## M5GO と PC の通信形式

`server.py` と `.ino` で一致させています。

- 送り先: `http://<PCのIPアドレス>:5000/motion`（POST）
- ヘッダー: `Content-Type: application/json`（`MIMAMO_DEVICE_TOKEN` を使う場合は `X-Device-Token` も）
- 本文: `{"motion":true}` または `{"motion":false}`
- 返事: 200 = 成功、400 = データの形式が違う、401 = 合言葉が違う

## PIR の接続ポートと GPIO 番号の根拠

**結論: Unit PIR は M5GO 下部の PORT B（黒）につなぎ、信号は GPIO36 で読みます。**

M5Stack の公式資料を3つ照らし合わせました。

| 資料 | 書かれている内容 |
| --- | --- |
| [Unit PIR のピン配置](https://docs.m5stack.com/en/unit/pir) | ケーブル4本のうち、黄色 = NC（未接続）、**白 = Digital Output（検知信号）** |
| [M5GO v2.7 のピン配置](https://docs.m5stack.com/en/core/m5go_v2.7) | PORT B は 黄色 = G26、**白 = G36** |
| [M5GO Kit の Arduino サンプル（Unit PIR）](https://docs.m5stack.com/en/arduino/m5go_kit/sensor) | `#include <M5Unified.h>` を使い、`sensorPin = 36` を `pinMode` / `digitalRead` で読む |

- Unit PIR の信号は白線 → PORT B の白線は G36 → **信号は GPIO36**。公式サンプルの 36 とも一致します。
- GPIO26 は黄色線で、Unit PIR では使われていません（NC）。
- 2026-10-18 に実機で確認しました。手を振ると GPIO36 が `HIGH`、離れると `LOW` に変わりました。
- PIR は少し離れた人の動きにも反応します。周りに人がいると `HIGH` になりやすいので、確認するときはセンサーの向きに注意してください。

## PC側の準備

### 1. ライブラリを入れる（最初の1回だけ）

1. スタートボタンを右クリック →「ターミナル」を開きます。
2. 次のように入力して Enter を押します。

```powershell
cd C:\SOS_LINK
pip install -r requirements.txt
```

### 2. PC の IP アドレスを調べる

IP アドレスは、ネットワーク上で PC を見分けるための番号です。M5GO はこの番号を使って PC にデータを送ります。

1. スタートボタンを右クリック →「ターミナル」を開きます。
2. `ipconfig` と入力して Enter を押します。
3. 「Wireless LAN adapter Wi-Fi」（有線なら「イーサネット アダプター」）の下にある **「IPv4 アドレス」**（例: `192.168.0.10`）をメモします。

注意:
- M5GO は **2.4GHz の Wi-Fi にしかつながりません**。PC と M5GO は同じルーター（Wi-Fi 親機）につないでください。
- PC を再起動すると IP アドレスが変わることがあります。変わったら `config.h` も書き換えて、もう一度書き込みます。ルーターの設定で PC の IP アドレスを固定（DHCP 予約）すると変わらなくなります。

### 3. ファイアウォールでポート 5000 を許可する

ファイアウォールは、外から PC への通信を止める Windows の防御機能です。M5GO からの通信を通すために許可します（管理者の権限が必要です）。

1. スタートメニューで「セキュリティが強化された Windows Defender ファイアウォール」と検索して開きます。
2. 左側の「受信の規則」をクリックします。
3. 右側の「新しい規則...」をクリックします。
4. 「ポート」を選んで「次へ」。
5. 「TCP」を選び、「特定のローカル ポート」に `5000` と入力して「次へ」。
6. 「接続を許可する」を選んで「次へ」。
7. 「プライベート」だけにチェックを入れて「次へ」（家の Wi-Fi が「プライベート ネットワーク」になっている必要があります）。
8. 名前に「ミマモリンク 5000」と入力して「完了」。

### 4. サーバーを起動する

```powershell
cd C:\SOS_LINK
$env:LINE_CHANNEL_ACCESS_TOKEN = "（LINE のチャネルアクセストークン）"
$env:LINE_USER_ID = "（送信先のユーザーID）"
python server.py
```

ブラウザで `http://127.0.0.1:5000/` を開くと家族用画面が表示されます。ほかの端末（スマホなど）からは `http://<PCのIPアドレス>:5000/` で開けます。

必要なら設定できる環境変数（環境変数 = プログラムに外から渡す設定値）:

- `IDLE_SECONDS` … 動きなしと判断する秒数（標準 30）
- `OFFLINE_SECONDS` … 通信が途絶えたと判断する秒数（標準 60）
- `MIMAMO_HISTORY_PATH` … 通知の記録を保存するファイルの場所（標準 `data/notifications.json`）
- `MIMAMO_SETTINGS_PATH` … 見守りの設定を保存するファイルの場所（標準 `data/settings.json`）
- `MIMAMO_DEVICE_TOKEN` … 合言葉。設定すると、`config.h` の `DEVICE_TOKEN` に同じ値を入れた M5GO からの送信だけを受け付けます

## M5GO側の準備（Arduino IDE）

### 1. Unit PIR をつなぐ

M5GO の本体下部（バッテリー部分）の **PORT B（黒いコネクタ）** に Unit PIR をケーブルでつなぎます。

### 2. Arduino IDE の準備（最初の1回だけ）

このPCには M5Stack ボードパッケージ（3.3.8）と M5Unified（0.2.26）が入っていることを確認済みです。別のPCで準備するときは次の手順で入れます。

1. Arduino IDE を開き、「ファイル」→「基本設定...」を開きます。
2. 「追加のボードマネージャのURL」に次を入力して「OK」。
   `https://static-cdn.m5stack.com/resource/arduino/package_m5stack_index.json`
3. 左側のボードのアイコン（ボードマネージャ）をクリックし、「M5Stack」と検索して「インストール」。
4. 左側の本のアイコン（ライブラリマネージャ）をクリックし、「M5Unified」と検索して「インストール」。「すべてをインストール」と聞かれたら、そちらを選びます（M5GFX も一緒に入ります）。

### 3. 設定を書き換える

1. Arduino IDE で「ファイル」→「開く...」→ `C:\SOS_LINK\m5go\mimamolink_m5go\mimamolink_m5go.ino` を開きます。
2. 画面上部のタブで `config.h` を開きます。
3. 次の3か所を書き換えて、「ファイル」→「保存」します。
   - `WIFI_SSID` … Wi-Fi の名前（2.4GHz のもの）
   - `WIFI_PASSWORD` … Wi-Fi のパスワード
   - `SERVER_URL` … `192.168.0.10` の部分を、上で調べた PC の IPv4 アドレスに変更（`:5000/motion` は残す）
4. `PIR_PIN` は `36` のままにします。

### 4. M5GO に書き込む

1. M5GO を USB ケーブルで PC につなぎ、電源を入れます。
2. 「ツール」→「ボード」→「M5Stack」→ **「M5Core」** を選びます。
3. 「ツール」→「ポート」→ M5GO の COM ポート（例: `COM3`）を選びます。
   どれか分からないときは、USB を抜いたときに消える番号が M5GO です。何も表示されない場合は、USB ドライバー（USB で通信するための追加ソフト）が必要なことがあります（未確認）。
4. 「ツール」の他の設定は変えなくて大丈夫です（標準の設定で容量に収まることを確認済み）。
5. 左上の「→」（書き込み）ボタンを押します。下に「書き込みが完了しました」と出れば成功です。

### 5. 動いているか確認する

M5GO の画面の見方（画面の文字は英語です。日本語の文字を入れると標準設定の容量に収まらないためです）:

| 画面の表示 | 意味 |
| --- | --- |
| `Motion: YES` / `Motion: no` | 動きあり / 動きなし |
| `WiFi: OK 192.168.x.x` | Wi-Fi に接続中（数字は M5GO の IP アドレス） |
| `WiFi: connecting...` | Wi-Fi に接続しようとしている（SSID・パスワード・2.4GHz かを確認） |
| `Send: OK (200)` | PC への送信に成功 |
| `Send: no PC (-1)` などマイナスの数字 | PC に届いていない（`SERVER_URL`、server.py が起動しているか、ファイアウォールを確認） |
| `Send: bad token (401)` | 合言葉が server.py と違う |
| `Send: bad data (400)` | データの形式が違う |

もっと詳しく見たいときは、「ツール」→「シリアルモニタ」を開き、右側の速度を `115200 baud` にします。次のような記録が出ます。

- `状態 PIR=0 WiFi=未接続 送信結果=-1` … 5秒ごとの状態（PIR=1 なら動きあり）
- `PIR(GPIO36): HIGH 動きあり` / `LOW 動きなし` … PIR が変化したとき
- `Wi-Fi接続: 192.168.x.x` … Wi-Fi につながったとき
- `送信 motion=true 結果=200` … PC に送ったとき（200 なら成功）

注意: シリアルモニタを開いたままだと、M5GO への書き込みができません（「COM3 が使用中」というエラーになります）。書き込む前にシリアルモニタを閉じるか、Arduino IDE を一度終了してください。

## PC だけで動作確認する方法

M5GO がなくても、PC から同じ形式のデータを送って確認できます。server.py を起動したまま、別のターミナルで実行します。

```powershell
cd C:\SOS_LINK
python -m unittest test_server -v
Invoke-RestMethod -Method Post -Uri http://127.0.0.1:5000/motion -ContentType 'application/json' -Body '{"motion":true}'
```
