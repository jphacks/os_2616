# ミマモリンク

[![IMAGE ALT TEXT HERE](https://jphacks.com/wp-content/uploads/2026/07/IMG_5316.png)](https://www.youtube.com/watch?v=piaNsc6ilBI)

## 製品概要

### 背景(製品開発のきっかけ、課題等）
一緒に住めない・遠くで暮らしているご高齢の家族に過度な干渉（プライバシーの侵害など）を避けた自然な見守りシステムの必要性が高まってます。しかし従来のセンサー通知システムでは「単に反応がない場合」にどこまで気に掛けたらいいのか判断しにくく、リアルタイムかつ心理的負担のない双方向のコミュニケーション能力が必要でした
### 製品説明（具体的な製品の説明）
ミマモリンクはIOTデバイスシステムのセンサー情報とWebアプリを連携させ、離れて暮らすご家族の生活リズムや現在の状態を自然に見守るプロトタイプシステムです。ご家族側の画面と本人側にある端末画面をで安全につなぎプライバシーを守りながらお互いの安心安全をサポートします。
### 特長
#### 1. 特長1
**プライバシーに配慮した非侵襲見守り**
カメラやマイクを一切使用せず、PIRmotionセンサー等による生活動線（起床、キッチン、トイレ、リビングなど）の検知のみで日常の安心を把握します
#### 2. 状態の変化を把握できる見守り画面
センサーの検知状況、最終検知時刻、通知履歴を家族用画面で確認できます。画面は自動更新され、手動で再読み込みする手間を減らします。
#### 3. 無反応と通信断を区別する通知機能
一定時間動きが検知されない状態と、デバイスからの通信が途絶えた状態を区別して管理します。状況に応じて通知することで、センサーが反応していないだけなのか、機器の接続に問題があるのかを判断しやすくします。

### 解決出来ること
-離れて暮らす家族が過度なプレッシャーを与えることなく、日常の安否や生活リズムを自然に把握できる。
-センサーの一定時間無反応時に、システムが自動でご本人へ優しく状態確認（声かけ）を行い、見守り漏れや連絡遅延を防ぐ。
-緊急時や不調時にワンタップで電話発信や状態報告が行え、迅速なコミュニケーションを促す。
### 今後の展望
-実機（IoTハードウェア）との通信安定性向上および数の増設。
-通知履歴の蓄積・グラフ化による、生活リズムの長期的な変化や健康予兆検知機能の拡張。
-複数家族での見守りシェアや、より多様なセンサーデバイスへの対応。
### 注力したこと（こだわり等）
* プライバシーと安心の両立： カメラやマイクによる常時監視ではなく、人感センサーを用いて必要な情報に絞った見守りを目指しました。
* 無反応と通信断の区別： センサーの無反応とデバイスの通信断を別の状態として管理し、通知の意味を分かりやすくしました。
* 継続的な見守りを意識した設計： 状態の自動更新、通知履歴の保存、通信復旧時の通知を組み合わせ、実際の運用を想定した仕組みにしました。
## 開発技術
### 活用した技術
#### API・データ
* HTTP API：M5GOからPCサーバーへのセンサーデータ送信、家族用画面への状態データ提供
* JSON：センサーデータおよび通知履歴の管理


#### フレームワーク・ライブラリ・モジュール
* Arduino IDE（C++）：M5GO側のプログラム開発
* M5Unified：M5GO本体の画面・機能の制御
* WiFi.h、HTTPClient.h：Wi-Fi接続およびHTTP通信
* Python、Flask：PC側サーバーの構築
* HTML、CSS、JavaScript：家族用見守り画面の開発
* requests：LINE Messaging APIへのリクエスト送信
* unittest：自動テスト
#### デバイス
* M5GO IoTスターターキット　V2.7


### 独自技術
#### ハッカソンで開発した独自機能・技術
一定時間の無動作を検知してご本人側画面へインタラクティブな確認ダイアログ（声かけ・状態応答）をトリガーするタイムアウト・ステータス管理ロジック
